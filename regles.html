📜 Règles du jeu

🎯 But du jeu

Incarnez la souris 🐭 et atteignez le drapeau 🏁 pour passer au niveau suivant, tout en évitant le chat !

⌨️ Contrôles

Utilisez les flèches directionnelles de votre clavier pour déplacer la souris dans le labyrinthe.

🧀 Bonus

Ramassez les fromages 🧀 pour gagner des points supplémentaires. De nouveaux fromages peuvent apparaître aléatoirement !

🐱 Le chat

Le chat vous poursuit activement dans le labyrinthe. S'il vous attrape, vous devrez recommencer le niveau actuel.

✨ Génération aléatoire

Chaque niveau est généré aléatoirement avec un labyrinthe unique. Plus vous avancez, plus les labyrinthes deviennent grands !
