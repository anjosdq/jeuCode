🐳 Docker & Containerisation

📄 Dockerfile

Voici le contenu du fichier Dockerfile utilisé pour conteneuriser l'application :

# 1. Base ultra-légère
FROM nginx:alpine

# 2. Copie des fichiers (HTML, CSS, Images)
COPY . /usr/share/nginx/html/

# 3. Documentation du port
EXPOSE 80

# 4. Lancement du serveur
CMD ["nginx", "-g", "daemon off;"]

🔍 Explication des instructions :

  • 1 FROM nginx:alpine - Image Nginx basée sur Alpine Linux (très légère, ~5MB)
  • 2 COPY . /usr/share/nginx/html/ - Copie tous les fichiers du projet dans le dossier web de Nginx
  • 3 EXPOSE 80 - Le conteneur écoutera sur le port 80
  • 4 CMD - Lance Nginx en mode premier plan (indispensable pour Docker)

⚙️ Commandes Docker

Pour construire et exécuter le jeu :

$ docker build -t attrape-souris .
$ docker run -d -p 8080:80 --name jeu-souris attrape-souris

✅ Le jeu est alors accessible sur : http://localhost:8080

📋 Autres commandes utiles :

$ docker ps # Voir les conteneurs actifs
$ docker stop jeu-souris # Arrêter le conteneur
$ docker start jeu-souris # Redémarrer le conteneur
$ docker rm jeu-souris # Supprimer le conteneur

🐳 Docker Compose

Alternative plus simple avec docker-compose.yml :

version: '3.8'
services:
  jeu:
    build: .
    ports:
      - "8080:80"
    container_name: attrape-souris
$ docker-compose up --build
$ docker-compose down

✅ Avantages de la containerisation

  • 🎯 Portabilité - Fonctionne sur Linux, macOS et Windows
  • 🚀 Léger - Image Alpine Linux extrêmement compacte
  • 🔒 Isolation - Environnement sécurisé et isolé
  • 📦 Déploiement simple - Une commande suffit
  • 🔄 Reproductibilité - Même environnement partout
